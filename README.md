# STUDIO · Backend

API REST de STUDIO, una plataforma para la gestión operativa de estudios de Pilates: alumnos, planes, turnos, reservas, profesores, pagos y caja.

**Stack:** Python 3.11 · Django 4 · Django REST Framework · PostgreSQL · Docker

> Proyecto en desarrollo. La documentación completa de instalación y de endpoints se va a ir sumando en `docs/`.
